# 화면·디스코드 문구 기준

학생이 읽는 모든 문구(안내 페이지, 커넥터 연결 화면, 디스코드 메시지·버튼, 확장 도구가 돌려주는 안내, 오류 메시지)에 적용합니다. 말투의 기준은 토스와 당근입니다. 짧고 다정하게 쓰고, 해야 할 행동을 바로 말합니다.

## 먼저: 짧게

학생이 지금 해야 할 일에 필요 없는 문장은 뺍니다. 동작 원리, 유지 기간, 면책 문구, 보안 설명은 화면에 쓰지 않고 개인정보 처리 페이지에만 둡니다. 한 줄로 못 줄이는 설명이면 빼는 쪽을 고릅니다.

- 나쁜 예: "Claude·ChatGPT에서 직접 커넥터를 추가하다 열린 화면일 때만 연결하세요. 남이 보낸 링크에서 연결하면 그 사람이 내 정보를 보게 돼요. 연결하면 claude.ai(으)로 돌아가요."
- 좋은 예: "직접 커넥터를 추가한 게 아니면 이 창을 닫아 주세요."

## 말투

- 해요체로 씁니다. "~합니다"체는 개인정보 처리 안내처럼 공식 문서에만 씁니다.
- 학생 입장에서 씁니다. 학생이 지금 무엇을 하면 되는지를 먼저 말하고, 이유는 짧게 붙입니다.
- 문장 길이를 섞습니다. 모든 문장을 짧게 끊으면 그것도 기계가 쓴 티가 납니다.
- 이모지는 디스코드 버튼과 제목에서 한두 개만 씁니다. 안내 페이지 본문에는 넣지 않습니다.

## 번역투 대신 이렇게

| 피할 말 | 이렇게 |
|---|---|
| ~할 수 없습니다 / ~할 수 없어요 | ~가 안 돼요, ~못 해요 |
| ~할 수 있습니다 (매 문장) | ~하면 돼요, ~해요 |
| ~인 것 / ~하는 것이 필요합니다 | ~해야 해요 |
| ~에 대한, ~에 관한 | 빼고 바로 명사로 ("설치 안내", "공지 알림") |
| ~를 통해 | ~로, ~해서 |
| ~에 의해 ~되었습니다 | 누가 했는지 주어로 |
| 해당 ~, 상기 ~ | 이, 그, 이름을 직접 |
| ~를 제공합니다 | ~를 보여 줘요, ~를 알려 줘요 |
| 진행해 주시기 바랍니다 | ~해 주세요 |
| 사용자, 귀하, 당신 | 주어를 빼거나 "학생", "내" |
| 성공적으로 완료되었습니다 | 다 됐어요, 연결됐어요 |
| 오류가 발생했습니다 | 무엇이 안 됐는지 그대로 ("KLAS에 로그인하지 못했어요") |

## 쓰지 않을 말

- "다양한", "편리한", "스마트한", "강력한", "간편하게", "손쉽게", "한 번에 모든 것을"처럼 내용 없이 좋아 보이려는 말
- "~를 경험해 보세요", "새로운 캠퍼스 라이프", "AI가 함께합니다" 같은 광고 문구
- "중요한 것은", "참고로", "단순히 ~가 아니라" 같은 연결어
- 없는 사실이나 숫자. 기능을 소개할 때는 실제로 되는 질문 예시만 씁니다.

## 안 될 때 쓰는 문구

세 가지를 이 순서로 씁니다. 무엇이 안 됐는지, 왜 그런지(한 줄), 학생이 지금 하면 되는 일입니다.

- 나쁜 예: "PC 에이전트가 연결돼 있지 않습니다."
- 좋은 예: "PC가 꺼져 있거나 잠자기 상태라 KLAS를 못 열었어요. PC를 켜고 로그인한 다음 다시 물어봐 주세요. 공지·학식·학사일정은 PC 없이도 볼 수 있어요."

## 색과 화면

- 대표 색은 광운대 상징 색(교표의 짙은 빨강)입니다. `--kw: #8B0E0A`. 버튼과 강조에만 쓰고, 배경은 흰색과 아주 옅은 회색(`#F7F8FA`)을 씁니다. 옅은 강조 배경은 `#FBEFEE`입니다.
- 글자는 `#191F28`, 보조 글자는 `#4E5968`, 선은 `#E5E8EB`입니다.
- 글꼴은 시스템 글꼴을 씁니다: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Pretendard", "Malgun Gothic", sans-serif`. 외부 글꼴은 불러오지 않습니다.
- 모바일 폭(360px)에서 먼저 맞춥니다. 버튼은 손가락으로 누르기 쉽게 높이 48px 이상, 모서리는 둥글게(12–16px) 만듭니다.
